# 测过什么，还有什么没验证

## 已实现的功能

题目和作答分开上传、裁剪旋转、文字核对、模型分析接口、原文引用检查、错题收藏、订正对照、确认或放弃保存、按知识点回顾、导出和回收站均已加入代码。另有一套固定题目的完整离线演示，使用独立存档。

“已实现”指代码和交互已经存在，不代表真实照片和任意数学题的处理质量已经达标。

## 测试记录怎么读

| 记录 | 说明了什么 | 还不能说明什么 |
|---|---|---|
| 单元、HTTP 和页面测试 | 测试覆盖的回复格式、确认、去重、保存及异常处理是否符合预期。 | 所有数学题都能讲对。 |
| 固定题离线演示 | 不用密钥也能查看完整操作，并区分示例与模型回复。 | 真实识图效果、模型速度和答案质量。 |
| 13 张自写合成图片 | 已准备不同学段、错答、缺条件和模糊图片等测试场景。 | 真实手机照片、手写作答的识别能力。 |
| 早期四题模块的真实调用记录 | 旧版接口和回复检查曾实际运行，也发现过提示泄露问题。 | 当前照片流程或当前提示词的效果。 |

[`release/verification.json`](../release/verification.json) 记录了首次公开版本的本地检查：2026 年 9 月 16 日，在 macOS、Python 3.12.5 和锁定依赖的新环境中，312 项应用测试通过，该次发布检查没有调用真实 API。

更早版本曾记录 303 项应用测试、12 项启动器测试和 11 项历史确认工具测试。这些属于不同范围的历史检查，不应直接相加当作当前公开版本的测试数。后续提交是否通过，以对应提交的 GitHub Actions 结果为准；发布记录不会自动代表后续版本。

## 尚未验证

真实 DeepSeek 照片识别、错因分析和订正质量还没有验收，人工评分尚未填写。空白评分表示没评，不是 0 分，也不是通过。

目前没有准确率、教师评分、学习提升、真实用户规模或留存数据。因此可以展示原型和已完成的软件检查，不能描述为已经验证有效、或已大规模使用的教学产品。

## 关于公开版本

首次公开版本由 `tools/export_public.py` 按 `tools/public_files.json` 导出，保留运行与测试所需文件，排除了本机私人路径、密钥、个人笔记、照片、原始调用报告和本地 Git 历史。

`PUBLIC_MANIFEST.json` 记录的是那次导出的文件及哈希；首次提交之后的修改以 Git 提交和差异为准。仓库第一条提交是整理后的版本，不是项目完整的原始开发历史。

## 接下来做什么

先用真实接口检查照片输入和分析，请教师核对质量并整理失败案例。之后观察用户实际操作，再根据发现的问题决定是否做手机端、多题拆分或复习推荐。程序测试、教学质量检查和学习效果研究，需要分别完成。
