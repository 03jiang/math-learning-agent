完整 JSON 样例未能消除所有结构问题。当前修订增加可选的 DeepSeek Beta strict 函数返回格式，并补齐重复字段的固定错误码；模式、地址和 schema 随计划冻结，不失败回退。这里只用单次指定函数的参数承载结果，没有工具执行或 Agent 循环。默认仍是 json_object；strict 已验证一条真实文字分析的兼容性，但订正和图片的真实兼容性仍未知，不能算作 B 阶段验收完成，详见[文字验证记录](STUDY_SMOKE.md)。
