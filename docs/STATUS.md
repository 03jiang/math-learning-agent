验证入口提供冻结计划、本机 HTTP 演练、持久调用记录、失败停止和确认保存，复用页面相同的服务与存储。普通页面尚未接入新 Agent 循环；真实照片与完整订正恢复尚未验收，本机演练不计作真实模型结果。

已实现双图录入、裁剪旋转、核对、分析适配、原文证据校验、错题收藏、订正对照、确认或放弃、知识点回顾、导出和回收站。提供固定题完整离线演示，使用独立存档。
