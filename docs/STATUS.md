# 当前交付状态

新版包括题目与作答分离、用户核对、步骤对照、确认收藏、再次作答、版本检查、重复确认去重、回收站及学习回顾。长期设置、本轮临时设置和同题上下文已接入主页面。

固定编排为主，另有默认关闭的有限只读工具调用。工具仅查询课程笔记和已授权历史，不允许模型自行保存、运行命令或标记学习完成。

## 已有验证

- 离线演示与测试覆盖页面、协议、受限数学证据、持久化、上下文、工具预算和发布白名单。当前提交的全量测试以 GitHub Actions 结果为准。
- 30 案例、15 家族的 A/B 离线对照框架可复现，使用合成输入和手写 HTTP 响应。
- 47 个已完成开发集回合有独立保存的 AI 预审；人工评分未完成。完整范围、失败分母和限制见 [评估状态](EVALUATION_STATUS.md)。

## 公开内容

仓库公开展示源码、自写合成样例、离线演示截图和聚合验证信息。白名单排除密钥、实际学生照片、个人错题本、原始调用记录和本机路径。历史验证说明是阶段记录，不替代当前评估状态。

根目录 `app.py` 为新版入口。早期四题版本移到 `legacy/`，仍复用的底层模块以显式 `legacy.*` 导入；全部回归测试在 `tests/`。

## 尚未完成

人工评分与争议复核、真实手机手写照片验证，以及真实学生学习效果研究均未完成。当前是单机单用户原型，不是线上教育服务。格式校验、离线测试或 AI 预审都不等于教师认可的教学质量。
