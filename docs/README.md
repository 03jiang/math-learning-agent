第一次了解项目，建议先读产品说明、架构和演示；判断评估进展请以当前状态为准。历史阶段记录保留问题与修复过程，不代表评估全部完成。

## 优先阅读

| 文档 | 用途 |

| [产品说明](PRODUCT.md) | 用户问题、设计取舍与功能范围 |
| [系统架构](ARCHITECTURE.md) | 主流程、确认保存和系统边界 |
| [演示脚本](DEMO.md) | 无密钥的离线演示步骤 |
