## 本次改动

- Agent 协议版本改为 `study-agent-v2`。完整 `chat.completion` 可携带可选 `index`，仅接受与调用数组位置一致的整数；归一化消息不回传该元数据。旧版无 `index` 格式继续支持。
- 缺少必填字段、其他额外字段、非法工具类型/名称、重复 ID、错误参数 JSON、流式分片和工具权限问题仍拒绝。旧单次文本解析器保持不变。
- 在解析工具请求前记录限长诊断：字段名、类型、结束原因、调用 ID、可选序号、函数名和原参数字符串。参数超过 2,000 字符明确截短，仅展示前 16 项调用；诊断不参与执行，也不把截短内容发送回模型。
- 未知字段只记录字段名，不保存其值；不记录 `reasoning_content`。凭证回显在记录前拦截，日志继续脱敏。诊断写入私人 Agent 日志及联调响应记录，排除在源码导出之外。

这些改动解决可复现的 `index` 兼容性问题和失败证据缺失。它们**尚未经过新的真实请求验证**，不能把旧失败改成成功。
