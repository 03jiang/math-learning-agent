# 五分钟演示脚本

按 README 安装，运行 `python -m study.launch --demo --port 8520`。演示使用独立目录，不需要密钥、不调用模型。响应速度和正确答案不能当作真实模型成绩。

| 时间 | 操作 | 要讲清的决策 |
|---|---|---|
| 0:00–0:40 | 介绍场景 | 学生需要看见差异并留下复习材料；需求仍待用户研究验证 |
| 0:40–1:30 | “载入演示题”，展示照片与原错答 | 题目与作答分开，保留错误过程；本次是固定方程题人工回放 |
| 1:30–2:20 | “识别这道题”，核对后分析 | 展示第一行 `+3` 与参考 `-3` 的差异，错因带追问，不贴能力标签 |
| 2:20–3:00 | 确认加入错题本 | 模型分析和长期记录分开，由用户决定保存 |
| 3:00–4:10 | 错题本中“填入演示订正”，核对、分析；先放弃，再分析并确认 | 放弃不改状态，保存保留原文和订正历史，不自动标为掌握 |
| 4:10–4:40 | 学习回顾，或回收站恢复 | 总结回到同类题复习，误删可恢复 |
| 4:40–5:00 | 展示测试与未验证项 | 工程流程已测，真实识图、人工评分与用户价值待验证 |

改动演示题或上传其他照片时，固定回放会拒绝，这是预期行为。普通入口可以连接模型处理新输入，真实照片效果尚未验收。裁剪旋转后若要继续固定回放，先恢复本轮原图。

收藏和订正的来源显示“离线演示 / 人工编写的固定方程题”。重启演示服务可恢复已确认记录，未确认草稿不保证恢复。
