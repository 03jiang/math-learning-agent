# 五分钟演示

先按 [README](../README.md) 安装，然后运行：

```bash
python -m study.launch --demo --port 8520
```

演示不需要密钥，不调用模型，数据单独保存。题目和回复都是事先准备的，因此不能用演示速度或答案正确与否说明真实模型的表现。

## 1. 说明用途（约 40 秒）

“这是一个整理数学错题的小工具。把题目和自己的解题过程放进来，对照参考步骤，再决定要不要存进错题本。重新做题后，还能回头看自己改了哪里。”

## 2. 载入题目并核对（约 50 秒）

点击“载入演示题”，展示题目照片和原作答。说明这是人工编写的固定方程题，演示版只是回放，不做真实识图。

点击“识别这道题”，核对右侧文字。重点是保留学生原来的错误，不要先改成正确答案；教师的批注也不应该算作学生的解题步骤。

## 3. 看步骤对照并收藏（约 90 秒）

勾选核对后，点击“分析这道题”。展示原作答中第一行的 `+3` 和参考做法中的 `-3`，再看对应的解释和检查问题。

“这里只说这道题可能错在哪里，不因为一次错误就判断学生的能力。分析看完以后，还没有保存。”

填写一条自己的提醒，再点击“确认加入错题本”。

## 4. 试一次订正（约 70 秒）

进入错题本，点击“填入演示订正”，核对后点击“分析本次订正”。先选择“不保存本次分析”，查看原记录没有变化；再分析一次，选择“确认保存本次订正”。

“新订正会另存一条，原作答还在。保存订正也不等于把这道题标成已经掌握。”

## 5. 查看复习记录（约 30 秒）

进入“学习回顾”，展示按知识点整理的题目。也可以把一道题移入回收站，再恢复，说明照片和订正历史都会保留。

## 6. 说明还没做完的部分（约 20 秒）

“目前能演示并测试的是操作和保存流程。真实照片识别、分析质量和学生使用后的学习效果，还需要另外测试。”

## 演示时注意

改动示例题或换成其他照片，固定演示会拒绝处理，并不是程序要为新题继续套用旧答案。裁剪、旋转后需要继续演示时，先恢复本轮原图。

保存记录的来源会标为“离线演示 / 人工编写的固定方程题”。重启后能恢复已确认保存的记录，未确认的草稿不保证恢复。普通入口可以配置真实模型，但当前照片效果尚未验收。
