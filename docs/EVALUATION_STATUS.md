# 评估范围与证据

人工评分未完成。AI 预审不能称为教师评测或开发者人工自评。

## 离线对照

冻结题集包含 30 个合成案例、15 个家族、15 道不同题干。20 个案例用于开发，10 个用于保留集，多轮共 94 个计划回合。既有完整离线演练记录为 91 个回合完成、3 个预设失败、101 次本机请求。它使用手写 HTTP 响应验证路由、工具预算、来源检查、上下文和执行账本，不衡量模型数学能力。

A 使用规则触发的固定查询流程，B 由模型选择有限只读工具，两者共享分析输出校验与确认保存边界。不能把离线程序可复现写成模型会正确选择工具。

## AI 预审快照

截至第四批开发集采集的独立本地账本，计划 20 个案例、58 个回合：完成 47、失败 7、阻塞 1、未运行 3。14 个案例的 A/B 全部回合完成，有 23 个完整配对回合和 1 个 B 单边完成回合。47 条完成回复已由 AI 助手逐条预审，人工已评数量为 0。此处仅公开聚合状态，不发布原始请求、响应、错题记录或本机路径。

已观察到局部成立的算式因整题方法错误而被判错、提示轮复述答案、恢复简洁设置后仍给长解释、引用真实但语义支持不足等问题。条件不足先澄清、只有答案不推断隐藏算法，在部分样例中有正面证据。这些观察不支持总体正确率、学习提升或 B 普遍优于 A 的结论。

分析操作要求完整参考答案，而请求可能仍携带 hint 偏好，存在共享协议设计冲突。预审按明确操作与本轮要求解释，有争议处留待人工复核。没有为了提高分数删除失败，或把失败行当作教学 0 分混入均分。

## 人工评分规则

使用 [冻结 RUBRIC](../evaluation/agent_ab_v1/RUBRIC.md)，逐回合填写数学步骤、帮助适配、工具使用、来源支持、历史使用五个 0～2 分维度，单列无依据归因、原文证据、评分人身份与争议。没有来源或未授权历史的对应维度留空。

汇总只比较双方完成且同一维度有评分的配对，保留配对数及失败、阻塞、未评分数量与统计分母。同题多轮不能作为独立样本做显著性结论。保留集未进行真实模型采集或用于提示调参；离线手写响应演练不等于保留集模型评测。
