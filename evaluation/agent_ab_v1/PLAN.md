# 数学 Agent 对照评估 v1：E1–E2

2026-09-24 固定用例与标准。本目录是新的评估准备，与旧 `teaching_cases.jsonl` 的四题 × 配置评估分开。先写参考与标准，再观察真实输出；本轮没有真实调用，没有人工评分。

## 样本与划分

30 条人工构造用例，20 条开发集、10 条保留集；每个题目家族包含两种学生作答情景。总共 **15 个题目家族、15 道不同核对题干、0 名真实学生**。其中 8 条含多轮：7 条三轮、1 条四轮；每版共 47 回合，两版共 94 行。不是 94 道独立题，更不是 94 名学生。

| 集合 | 题目家族 | 用例 | 每版回合 | 两版最大模型请求 |
|---|---|---:|---:|---:|
| 开发集 | 异分母相加、小数相加、整体的分数、一次方程、三角形面积、分数除法、运算顺序、单价、平行四边形缺高、平方方程 | 20 | 29 | 145 |
| 保留集 | 折扣逆求原价、二元一次方程组、负数不等式、圆面积、等可能概率 | 10 | 18 | 90 |
| 合计 | 15 个家族 | 30 | 47 | 235 |

以数学任务结构划分家族；换题回合也检查归属。相同题干和同一家族不能跨集，小改数字/学生作答仍在同组。开发集的异分母题复用早期已见的 b01/b02 题型；不宣称全部是从未见过的新题。知识点之间仍有联系，这不是严格的跨学科外推实验。初稿中的“单价/速度”同构模板已在真实评估前调整为二元一次方程组，避免背景替换造成泄漏。

数据是开发者自写而非独立命题；保留集表示未据其真实模型回复调参，不表示开发者没读过题目。查看真实保留回复并据此修改策略后，必须登记为已用，不能继续称作未见验证集。旧的 48 配置评估、13 张照片、B 阶段真实调用分别记账，不合并分母。

## 公平对照

| 项目 | A 固定流程 | B 有限工具循环 |
|---|---|---|
| 教学要求 | 共用主程序分析／追问提示词，另加固定流程说明 | 共用相同分析／追问提示词，另加工具协议 |
| 资料获取 | 学生明确说“笔记/资料”时查笔记，“以前/历史”且已授权时查历史；每类最多一次 | 模型按需选择只读工具，最多3次 |
| 模型上限 | 每个回合1次 | 每个回合最多4次；全部计数 |
| 近期对话 | 最近1轮 | 主程序上下文管理，最多4轮 |
| 设置和任务 | 相同长期设置、本轮覆盖、待做任务；换题清空 | 相同输入与规则 |
| 最终协议 | result + citations；复用相同分析/追问和原文引用校验 | 相同 |
| 存储边界 | 评估没有收藏或掌握写入入口 | 相同；Agent 日志中的决定保持空 |

这是**整个工作流的对照**，基线也有合理的教学和证据要求。相同模型、温度、thinking、输出 token 上限、题干、学生作答、设置与可访问资料；轮换 A/B 顺序。实际得到的资料、上下文长度、请求次数可以不同，均记录，不把差异全部归因为 prompt、检索或记忆单个组件。此轮并非“普通提示词 vs 协议提示词”的纯提示词消融实验。

基线取学生请求中的明确查询词，无法提取时用限长请求文本；不从人工作答标准或场景标签生成查询。历史为隔离目录中自写样本，含相关、无关、365天前和用户停用记录。笔记为原有8份加本评估3份规则说明，不含本次参考答案。双方都受相同资料权限与工具总时间3秒约束。B 每回合总时间最多180秒，A 是单次60秒模型请求加最多3秒资料查询；时延差异按实际记录报告。

只发送白名单字段。`human_only`、评分标准、标签、故障设置、原始 OCR 不进入模型上下文。数学分析先比较相同的已核对文本，两个模拟 OCR 差异保存在用例中；一条未核对数字要求澄清。本轮不调用 OCR、不计算识图准确率；端到端手机照片另做评估。

## 零密钥运行

在项目根目录、已安装锁定依赖的 Python 环境中：

```bash
python -B -m tools.evaluate_agent preview --output evaluation_runs/ab-preview-v1
python -B -m tools.evaluate_agent local --split all --output evaluation_runs/ab-local-v1
python -B -m tools.evaluate_agent scores --output evaluation_runs/ab-local-v1
python -B -m unittest test_agent_evaluation -v
```

默认只预览开发集；`--split reserved` 单独准备保留集。输出目录必须不存在，不覆盖旧文件。预览冻结代码、笔记、用例、标准、模型配置和范围；后续回合依赖实际前序回复，所以预览只标为骨架，不伪装成已经发出的完整请求。源码/配置/用例变化拒绝复用。本机演练要求与冻结同一 UTC 日运行，以固定历史过期边界；发生失败/中断不重复运行原目录。

输出包括 `manifest.json`、每回合 `previews/`、实际 `rows/`、Agent 日志、`scores.json`、`REPORT.md`、`status.json`、`scoring-summary.json`。实际每个 HTTP 请求在发送前登记 payload 与哈希，回复中的内部推理和凭证不进入报告。历史种子写入隔离 `scopes/`，不接触日常错题本，不形成用户收藏。

**离线响应不是解题器**：它用固定澄清/提示文字测试传输、上下文和边界；不能用此输出评分教学质量。e19 对双方注入笔记工具故障；e26 对 B 注入越权工具响应。故障行照计入失败，不包装成模型成功率。失败结束当前模拟会话并阻塞其后续回合，其他独立本机用例继续；这项继续规则仅适用于手写离线演练。

## 后续真实评估的验收门槛

原离线入口保持 preview/local/status/scores。随后新增的独立[开发集执行账本](../../docs/AB_LIVE.md)提供零调用预览和显式批准后的真实入口，复用上述A/B服务与评分表；每次HTTP先占名额与估算预算，任何失败停止整份计划，不自动续跑。真实调用尚未执行，保留集入口尚未开放。235次是全量上限计算，不是调用批准，也不是建议一次发完；之前13次真实调用与1元预算不能挪用。

预算与实际费用当前为 null，不是免费。真实阶段记录所有请求、失败、未知状态、token与费用证据，未知仍空。先开发集一次明确假设/改动/复测，再冻结版本运行保留集。人类评审后填写结果；若继续暂缓人工评分，保持空表，不用模型自动代评。

待重点观察的协议边界：建模/运算顺序可能错误，但学生写出的数值等式本身成立（如 e06/e09/e13/e22）。不能为了通过整体错答格式而把合法数值运算标错。若当前协议无法忠实表达，记录为协议失败并修订开发版本，不调整人工标准来迁就输出。该问题尚无新模型结果。
